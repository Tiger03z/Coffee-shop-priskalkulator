# Coffee-shop-priskalkulator
I dette repoet finner du utgangspunktet for å lage en priskalkulator til en kafé. Bytt ut README.md med en beskrivelse av 
prosjektet ditt.

# Beskrivelse av prosjektet

## coffee shop oppdraget
    Dette prosjekte handler om at jeg skal lage en kalkulator program for en kaffe sjappe, 
    der jeg kan skriver inn bestilingen min så får  ut hvor mye det koster, Du kan ha så 
    mange kopper du føler for og du kan velge melo forjelige smaker, størelser
    og tilbhør, all informasjonen du setter inn kommer i en recit på sluten 
    av programet for åversikt over hva du har sjøpt

## Problemer som kan sje og hvordan sjøre programet
    1. Du må ha instaler den nyeste versjonen av Python
    2. gå inpå filen som heter coffeshop.py
    3.du kan prøve å finne en knapp som ligner på en trekant/pil og når du trykker på den vil programet skjøres
    
    $ du kan åpne terminal med comand+j men usiker på hvor du skal derreter

    # ting som kan gå gale
    du bruker windos. og da kan det være du må gå inn i koden
    å finne #windows og unmarek coden som stå under og marke 
    coden uder der igjen med #print(f"{kaffer[sm][f'{sm}smak']} osv. det samme gjelder mac

    finner ikke start knappen: 
        1. prøv å restarte programet  
        2. avinstaler python og instaler på nyt
        3. run or debug er sjult (dobbel klikk på en firkant med strek nedover og vis run or debug)

## programmet består av

    Jeg bruker masse av if/elif/else comander for mase vis av forslag som går i ordbøker
    for å lagre informasjon med å bruke .append
    bruker funkjoner for lettere leing av programet
    jeg har tall inni ordbøkene for lettere debuging
    global for å hvise programet hvor variablene er/si til programe at de eksisterer
